# Project 1: C Programming & Embedded Systems

This repository contains the solutions for Project 1, focusing on foundational C programming, control flow, functions, recursion, and a hardware simulation using Tinkercad.

### Structure:
- **Question 1:** C Program for a Water Quality Monitoring System (Includes variables and arithmetic logic).
- **Question 2:** C Program for a Mobile Money Transaction Menu (Includes switch statements, loops, break, and continue).
- **Question 3:** C Program for Delivery Distance Analysis (Includes array processing, reusable functions, and recursion).
- **Question 4:** Arduino-based Smart Parking System (Tinkercad simulation code and report).

All documentation and technical explanations are included in markdown files within their respective question folders.
